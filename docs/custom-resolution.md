# 自定义分辨率：问题定位与修复

## 现象

创建自定义分辨率后“看不到效果”，或在 RX 6800 XT 上创建失败、删除失败。实测环境：
RX 6800 XT（Navi 21）、驱动 32.0.21045.16010、驱动内置 ADLX 1.4、显示器 2560×1440@240
（EDID 范围 48–240 Hz，最大像素时钟 1080 MHz）。

## 结论

ADLX 的自定义分辨率接口本身可用，但驱动（1.4）在这个功能上有几个坑：

1. **`IsSupported` 不可靠**。列表非空时它可能返回 `false`，但 `CreateNewResolution`
   仍然会成功。原实现用 `IsSupported` 硬拦截，会误报“该显示器不支持自定义分辨率”。
2. **重复模式会留下删不掉的幽灵条目**。对同一个 `w/h/refresh` 连续创建，驱动会接受
   并返回 `ADLX_OK`，但随后 `DeleteResolution` 长期返回 `ADLX_INVALID_ARGS`。
3. **高刷新率的输入时序会被驱动改写**。驱动按 CVT-RB 的 460 µs 垂直消隐重算
   `vTotal/pixelClock`：例如 160 Hz 输入 `vTotal=1460`，实际存储为 `vTotal=1555`。
   部分组合（本机 2560×1440@160、@200）可以创建但无法删除。
4. **创建成功 ≠ 已生效**。原界面只提示“可在分辨率下拉中选择”，没有真正切换模式；
   用户很容易认为功能无效。
5. **持久化在注册表**：`HKLM\SYSTEM\CurrentControlSet\Control\Class\{4d36e968-…}\0000\DAL3_DATA\common\EDID_<…>\mode_timing_override`。
   驱动把自定义模式列表存在这里，进入异常状态后只能清掉该值并重启显卡驱动/系统。

驱动对“自定义刷新率”的上限与分辨率有关（本机 2560×1440 约 163 Hz、1920×1080 约 200 Hz
可正常创建并删除；更高刷新率会被拒绝或变成幽灵条目）。这是驱动侧限制，应用无法绕过。

## 根因：对话框返回值

最直接的“无反应”原因不在 ADLX，而在界面：`CustomResDialog` 的“创建”按钮只设置了
`Accepted = true`，没有设置 WPF 的 `DialogResult`。调用方用的是：

```csharp
if (dlg.ShowDialog() != true) return;
```

`Close()` 没有设置 `DialogResult` 时 `ShowDialog()` 返回 `null`，所以创建逻辑**从未执行**。
现在“创建/取消”都会显式设置 `DialogResult`，并在对话框内增加“该模式已存在”的校验，
避免用默认值（当前模式）点创建时只得到驱动错误。

## 修复

`native/rt_core.cpp`：

- `rt_cr_add_ex`
  - 不再用不稳定的 `IsSupported` 拦截，直接尝试创建。
  - 创建前对比现有自定义列表，同一 `w/h/hz` 返回 `-200`（重复）。
  - 创建后回读列表，确认条目真实存在；否则返回 `-202`。
- 新增 `rt_cr_reset(keepBackup)`：清理 `DAL3_DATA\common\EDID_*\mode_timing_override`，
  可选把原始二进制备份到 `%LOCALAPPDATA%\RDNA Panel\cr-backup-*.bin`。
- `rt_cr_del` 的错误码由界面翻译成可读原因。

`MainWindow.xaml.cs`：

- 创建成功后**立即切换**到新模式，复用已有的 15 秒确认/自动回滚流程。
- 每个自定义模式提供“应用”和“删除”两个操作。
- 创建/删除失败时显示具体原因（重复、驱动拒绝、回读缺失等）。
- 新增“修复自定义分辨率列表”：清理持久化数据并提示重启显卡驱动/系统。

## 使用建议

- 自定义分辨率优先用于“显示器没有的宽高比/分辨率”，刷新率不要超过该分辨率现有最高值；
  驱动会拒绝过高的刷新率。
- 如果列表进入异常状态（创建成功但下拉里没有、删除一直失败）：点“修复自定义分辨率列表”，
  然后重启显卡驱动或重启系统。持久化数据会先备份。

## 验证

- `add 2560×1440@150` → `0`；再次创建同参数 → `-200`；删除 → `0`。
- `rt_cr_reset(1)` 删除注册表值并生成 `cr-backup-*.bin`（164 字节，空列表结构）。
- 清理后重启显卡驱动，`rt_customres` 返回 0，Windows 模式列表恢复为原生
  `60/120/144/240`。
- 创建 `2560×1440@150` 后立即 `EnumDisplaySettings` 已能看到 150 Hz，`ChangeDisplaySettings`
  切换成功并可回滚。
